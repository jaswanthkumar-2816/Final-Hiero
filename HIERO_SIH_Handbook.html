1. Smart India Hackathon & Problem Statement

🇮🇳 Core National Impact & Problem Statement

Over 80% of Indian engineering and degree graduates face severe employability challenges due to a gap between academic curricula and evolving industry Job Descriptions (JDs). Students in Tier-2 & Tier-3 cities lack affordable career counseling, regional language guidance, and ATS resume formatting expertise.

Government Initiative Alignment

  • Skill India Initiative: Identifies individual skill gaps and maps customized learning paths.
  • National Education Policy (NEP 2020): Promotes regional language learning by providing tutorial video roadmaps in 5 Indian languages (English, Hindi, Telugu, Tamil, Kannada).
  • Digital India: Democratizes top-tier placement tools to any student with internet access at zero cost.

4. Score Calculation Formulas & Parameters

1. Overall Match Score Formula (0 - 100)

Final Score = Min(100, SkillsPts + ProjPts + ExpPts + EduPts + BonusPts)

  • Skills Match (40 Pts): (Matched Skills / Total JD Skills) * 40
  • Projects (25 Pts): Base 15 Pts for having projects + 10 Pts for JD skill alignment.
  • Work Experience (15 Pts): Base 9 Pts + 2 Pts per year of experience (Max +6 Pts).
  • Education (9 Pts): Presence of recognized degree (B.Tech, M.Tech, B.Sc, Diploma).
  • Extra Skill Bonus (10 Pts): +1.5 Pts per extra technical skill beyond JD demands.

2. ATS Compatibility Score Formula (0 - 100)

ATS Score = (0.30 * Keywords) + (0.20 * Structure) + (0.20 * Readability) + (0.20 * Formatting) + (0.10 * Action Verbs)

  • Structure (20%): Detects standard headers (Experience, Education, Skills, Projects, Summary).
  • Action Verbs (10%): Detects power verbs (Built, Developed, Optimized, Architected, Automated).
  • Quantifiable Impact (20%): Scans for metrics (%, $, 500+ users, 2x growth).
  • Formatting (20%): Word count range (300-800 words = 95 Pts optimal).
  • Readability (20%): Average words per line (8-20 words/line = 92 Pts).

6. Top 15 SIH Jury Questions & Answers

Q1 What national problem does HIERO solve for Smart India Hackathon?
Answer: HIERO bridges the employability gap for Indian students by evaluating skill alignment against real-world Job Descriptions. It directly supports Skill India, Digital India, and NEP 2020 by providing free, localized upskilling roadmaps in 5 regional languages (English, Hindi, Telugu, Tamil, Kannada) for students in Tier-2 and Tier-3 cities.
Q2 How is HIERO different from ChatGPT or generic resume builders?
Answer: ChatGPT only provides generic text advice without verified resource links or ATS PDF rendering. Generic resume builders only format text without skill gap analysis. HIERO is an end-to-end pipeline: it extracts text from PDFs, calculates a mathematical match score, curates real 5-language YouTube video playlists and LeetCode problem links, and compiles 22 ATS-optimized PDF templates.
Q3 How do you extract text from uploaded resumes (including scanned PDFs)?
Answer: We use a hybrid extraction engine. Vector PDFs are parsed using pdf-parse, and DOCX files are extracted via mammoth.js. If the extracted text has fewer than 50 characters (indicating a scanned image-based PDF), our system automatically triggers Tesseract.js OCR to extract image text accurately.
Q4 How is the Overall Match Score calculated mathematically?
Answer: The score (0-100%) is calculated across 5 parameters: Technical Skill Overlap (Max 40 Pts), Project Skill Alignment (Max 25 Pts), Work Experience & Years (Max 15 Pts), Degree Qualification (Max 9 Pts), and Extra Skill Bonus (Max 10 Pts).
Q5 How does the 5-language regional tutorial generator avoid hallucinations?
Answer: We do not rely on LLMs to generate video URLs. Instead, our backend queries the YouTube Data API v3 dynamically using skill keywords combined with regional language parameters (e.g., "SQL tutorial in Telugu", "React tutorial in Hindi"), guaranteeing 100% real, active video tutorials.
Q6 Which AI models power HIERO, and what happens if the AI API fails?
Answer: We use Groq SDK (llama-3.3-70b) as primary for sub-second parsing and OpenRouter (gpt-4o-mini) as secondary. If internet or API limits occur, our custom regex & pattern-matching parser (parseResumeTextRuleBased) takes over seamlessly with zero system downtime.
Q7 How does the AI Voice Mock Interview system work technically?
Answer: The frontend uses the browser's native Web Speech API for Speech-to-Text (STT) and Text-to-Speech (TTS). Candidate spoken answers are sent to our Express backend, evaluated against job role criteria by Groq AI, and returned with immediate score ratings and constructive feedback.
Q8 How does the Resume Builder render and export 22+ ATS templates as PDF?
Answer: The frontend dynamically renders live HTML/CSS resume templates. When the user clicks "Download PDF", our backend uses Puppeteer (headless Chrome) to compile the DOM into a high-resolution, vector PDF document.
Q9 Why did you build a Unified Gateway (gateway.js) instead of separate microservices?
Answer: A single Express Gateway (port 2816) eliminates cross-port CORS issues, reduces server memory footprint, simplifies cloud deployment (Render/Railway), and centralizes authentication and static file serving.
Q10 How does MongoDB Atlas store and organize your application data?
Answer: MongoDB Atlas stores schemas for User Profiles, Auth Credentials, Saved Resumes, Review Ratings, and Analytics Logs using Mongoose ODM with indexed fields for fast data retrieval.
Q11 How do you handle user authentication and session security?
Answer: We implement Passport.js supporting Google OAuth 2.0 and GitHub OAuth, along with traditional email/password sign-in hashed using bcryptjs and stateless JSON Web Tokens (JWT).
Q12 How will HIERO scale to millions of Indian college students?
Answer: HIERO's lightweight Node.js gateway is stateless and horizontal-scaling ready. Static assets are compressed via gzip/brotli, and database queries are indexed on MongoDB Atlas, allowing thousands of concurrent users per node instance.
Q13 What is your deployment architecture and cost model?
Answer: HIERO is deployed on Render/Cloud VM using Docker containers. Resource curation relies on open YouTube and public coding APIs, keeping operational costs extremely low (~0.01 per user analysis).
Q14 How can state government placement cells or universities adopt HIERO?
Answer: HIERO can be white-labeled and integrated into university placement portals via REST APIs, allowing institutional placement officers to view aggregated skill analytics across entire graduating batches.
Q15 What is the future roadmap for HIERO post-hackathon?
Answer: Our roadmap includes developing a native React Native mobile app, expanding regional support to 10+ Indian languages, integrating automated GitHub portfolio verification, and building enterprise recruiter search dashboards.
