TECHNICAL APPROACH

SMART INDIA
HACKATHON 2026

Deterministic scoring (not LLM)

  • JD match — skill coverage 70% + projects 12 + experience 10 + education 8. Extra skills do not inflate the score.
  • ATS — keywords 30% + formatting 20% + readability 20% + structure 20% + action verbs 10%.
  • Skill gap — set difference of JD vs resume; JD skills ranked Critical / Important / Optional by frequency × position.
  • Eval grade — MCQ index match + Python test equality. Score = 60% quiz + 40% coding. Pass 70/75/80. Certificate only if passed.
  • Mastery — 30% practice + 60% assessment + 10% recency decay.

Retrieval + tracing

  • TF-IDF + cosine — caption windows 30–60s; locate the exact YouTube clip for a weak subtopic (local vectors, no paid embedding API).
  • Interview rank — company/role/JD/resume weights; Jaccard + bigram dedup (reject ≥ 0.45). LLM only phrases the top-4.
  • Python sys.settrace + JS Acorn AST in Node vm — step-level visualize; C/C++/Java transpile then trace.
  • Proctor — BlazeFace + COCO-SSD on client; tab-switch / copy-paste logged on server.

Where Groq / Deepgram sit

  • Groq blends match score only if it is within ±25 of the formula (70% formula, 30% AI). Else formula wins.
  • Groq generates eval questions and interview wording — never the grade.
  • Deepgram Nova-3 STT / Aura-2 TTS for interview voice (not browser Web Speech).
  • FastAPI :5050 stores jobs/applications. Gateway :2816 is the only privileged hop.

FEASIBILITY AND VIABILITY

SMART INDIA
HACKATHON 2026

Why this is buildable now

  • Already running locally: Final Hiero :2816, Academia :2410, Connect :2004, jobs engine :5050.
  • One Node gateway, not a microservice fleet. Lazy-loaded routers for cheap cloud deploys (Render-ready).
  • If Mongo is down, auth and jobs still fall back to JSON files.
  • Open APIs we already wire: Groq, YouTube Data API, Deepgram, Edge-TTS, Razorpay.

Risks we actually hit

  • LLM / STT cost and outage → Groq + OpenRouter + rule-based parse fallback.
  • Rural bandwidth → PWA / offline.html, video via YouTube not self-hosted.
  • Campus adoption → Bridge portal is the institutional face; students stay on Hiero.
  • Cheating on eval → camera + tab heartbeat; grades never trusted from the client.

Business model (honest)

  • Core learn / apply loop free for students.
  • Razorpay plans already in the student app (₹9–₹249) for resume templates and extras.
  • Campus license later: Bridge as the placement-cell product.
  • Pilot: one college drive + one HR inbox, not a national rollout on day one.
